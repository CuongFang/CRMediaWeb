# CRMedia — Official Landing Page & Download Website

Website giới thiệu chính thức và trang tải phần mềm **CRMedia v3.0.2** (Windows `.exe` · macOS Apple Silicon `.dmg` · macOS Intel `.dmg`), tích hợp sẵn:
- **Hero & 5 Motion tương tác trực tiếp bằng ảnh cưới thật** (Lọc Ảnh AI & ArcFace-R50, Dàn Trang Album 300 DPI, Studio Làm Video Slide GPU RTX, Cổng Gửi Khách Zero-Trust & Hệ Sinh Thái Studio).
- **Trọn bộ 5 Video Motion 16:9 dưới 1 phút** có thuyết minh tiếng Việt & phụ đề động.
- **Bảng giá & Thanh toán SePay VietQR** (Dùng thử 3 ngày miễn phí · Gói Tháng 99.000đ · Gói Vĩnh Viễn 999.000đ).
- **Khu vực Tải Ứng Dụng** tự nhận diện Windows / macOS.

## Bật trang web chạy online miễn phí (GitHub Pages)
1. Vào **Settings → Pages** của repo này trên GitHub.
2. Ở mục **Build and deployment → Source**, chọn **Deploy from a branch** → nhánh **`main`** · thư mục **`/ (root)`** → bấm **Save**.
3. Sau 1 phút, website sẽ hoạt động công khai tại: `https://cuongfang.github.io/CRMediaWeb/`

## Thay đổi đường dẫn tải bộ cài
Chỉnh sửa biến `DOWNLOAD_CONFIG` ngay đầu tệp `app.js`.
